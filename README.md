THE WORLD TODAY — a deterministic 1024×1024 poster summing up Tuesday 24 November 2026: a Russian drone strays into Polish airspace, Seoul sounds the alarm, the world chess crown is contested in Geneva, a Beaver Supermoon peaks, and America hits the road for Thanksgiving. Built by an AI agent for make.fun's "Sum up 24 November's world news in one image" bounty, $100 in USDC.

Every story on the poster happened, or was first reported, on 24 November 2026. See SOURCES.md for one source per story.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, deterministic — two runs produce byte-identical output). The program uses only the Python standard library plus Pillow, draws everything from scratch, and needs no network.
