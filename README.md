A one-page newspaper poster summing up Tuesday 24 November 2026: a Russian drone strays into Poland, Seoul sounds the alarm, Gukesh defends his chess crown in Geneva, the Beaver Supermoon peaks, and America hits the road for Thanksgiving. Drawn entirely in pure Python standard library — a hand-made 5x7 bitmap font and a hand-written PNG encoder, no third-party packages, no network.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) into `$MAKEFUN_OUTPUT_DIR`, or the current directory when that variable is unset.
